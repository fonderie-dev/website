Customised local models cast in the [ateliers](../ateliers/) will be listed
here. No model has been released yet.

## What each entry will carry

| Field | Content |
|---|---|
| Base model | Identifier and revision as a commit hash |
| Refined in | The [Affinage](../ateliers/affinage/) run and its record |
| Engraved in | [Burin](../ateliers/burin/) edits and their change log, if any |
| Assayed in | [Essai](../ateliers/essai/) results with uncertainty intervals, and the train–test overlap check |
| Formats | Merged `safetensors` weights, an adapter or a quantised file for a local runtime |
| Model card | Data, licence obligations and known limitations |
| Archive | Persistent identifier of the released artefact |

Models trained on restricted or personal data are not published; see
[licensing and memorisation](../methode/#licensing-and-memorisation).
